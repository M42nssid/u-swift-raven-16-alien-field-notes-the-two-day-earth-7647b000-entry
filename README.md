## What the bounty asks

One original line of plain text, at most 200 characters: a review of planet
Earth left by an alien tourist. A judge model ranks the lines pairwise on
funniness and originality, weighing the alien's one-line review of Earth
first, then funniness, originality, whether it reads like a real review, and
how tight the writing is.

## The entry

`main.ts` (Node 22, stdlib only, no network, no clock, no randomness) writes
the single line to `/output/entry.txt`:

> Earth: 5/5 stars. The locals grow food in dirt, cook it with fire, then photograph it before eating — in case it tries to escape.

Run it with `node main.ts`. Running it twice produces byte-identical output.
